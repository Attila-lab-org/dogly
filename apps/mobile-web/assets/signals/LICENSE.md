# Dogly Signals audio assets

Bundled audio is used as a curated stimulus, not as a translation, command or
scientific claim about universal canine meaning.

## Public-domain fixtures

The following files are local copies of samples from
`petdecoder/pet-decoder-audio-fixtures`, sourced there from the Red Library
Sound Effects Collection (Craig Smith / USC) and published as CC0 1.0:

- `attention-soft-01.mp3` — source file `dog_bark_small.mp3`
- `play-invite-01.mp3` — source file `dog_growl_play.mp3`
- `curiosity-soft-01.mp3` — source file `dog_panting.mp3`

Source:
https://huggingface.co/datasets/petdecoder/pet-decoder-audio-fixtures

License:
https://creativecommons.org/publicdomain/zero/1.0/

## Public-domain natural dog recording

- `contact-call-01.mp3` — Wikimedia Commons MP3 transcode of `Dog.ogg`,
  recorded by soerena and released into the public domain.

Source and license declaration:
https://commons.wikimedia.org/wiki/File:Dog.ogg

## Product constraint

These recordings are not evidence that a sound has a fixed meaning. Category
placement is an experiment configuration that must be validated through
product research and safety review before public release.
